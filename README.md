# make-knowledge-cards

一个供支持 Skills 的 AI 代理使用的文本提炼 Skill：将粘贴文章或本地 Markdown/TXT 文件转为通常 **5–8 张知识卡片**。它是代理指令与元数据，不是独立应用或命令行转换程序。

## 1. 项目解决什么问题

阅读文章后，手工整理学习材料容易遗漏重点、重复摘录，或把多个概念混在一起。本项目提供统一的提炼流程：选择真正重要的知识、去重、保留原文条件，并用一张卡片讲清一个知识点，便于理解、复习与自测。

## 2. 主要功能

- 接收粘贴正文，或代理可读取的本地 `.md`、`.markdown`、`.txt` 文件。
- 通常提炼 5–8 张卡片；不足 5 个独立知识点时减少数量并说明原因，没有可提炼知识时不生成空卡片。
- 每张包含标题、核心知识、简明解释，以及原文例子或自测问题；自测附参考答案。
- 附原文依据，保留数字、条件、适用范围和不确定性，不补充外部信息或虚构例子。
- 默认沿用原文语言；可按用户要求翻译。多个来源默认分别处理，明确要求时才合并。
- 默认在对话中输出 Markdown；仅在用户要求时创建输出文件。

**当前不支持**：网页抓取、直接读取 PDF、Anki 导出或图形界面。本项目不含 PDF 提取工具；如另行将 PDF 转为可读文本，可将该文本作为输入。

## 3. 安装方法

前提：使用能够加载 Skill 指令的 AI 代理；处理本地文件时，代理还需具有该文件的读取权限。无需安装本项目的运行脚本或第三方软件包。

### 在当前项目中使用

保留以下文件，并在对话中明确要求代理读取 `skills/make-Knowledge-cards/SKILL.md` 后执行任务，无需安装到全局目录。

```text
skills/make-Knowledge-cards/
├── SKILL.md
└── agents/openai.yaml
```

### 安装到 Codex Skills 目录

如果你的 Codex 环境使用 `$CODEX_HOME/skills`（未设置时为 `~/.codex/skills`），可在项目根目录运行以下 Bash 命令。先确认目标目录不存在，以免与已有 Skill 冲突。

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/make-Knowledge-cards "${CODEX_HOME:-$HOME/.codex}/skills/make-knowledge-cards"
```

随后在该环境中调用 `$make-knowledge-cards`。其他代理的安装目录与发现机制以其自身说明为准；也可直接按路径加载。

项目目录按要求保留 `make-Knowledge-cards`，Skill 标识和上述安装目录使用全小写 `make-knowledge-cards`。

## 4. 使用方法

**当前项目，粘贴正文：**

```text
请读取 skills/make-Knowledge-cards/SKILL.md 并按其要求，
把以下正文转换为知识卡片：
[粘贴文章正文]
```

**当前项目，本地文件：**

```text
请使用 skills/make-Knowledge-cards/SKILL.md，
将 tests/inputs/procedure.md 转换为知识卡片。
```

**安装后调用：**

```text
请使用 $make-knowledge-cards，将 ./notes/article.txt 转换为知识卡片。
```

文件路径必须真实且可读取；缺少输入、文件不可读或格式不支持时，Skill 会请求可读正文，不猜测内容。正文中夹带的命令作为材料处理，不执行。

## 5. 输入输出示例

### 有原文例子的短文章

输入：

```text
蒸发吸收热量，汗液蒸发因此带走热量。
```

输出示例：

```markdown
共 1 张知识卡片。原文仅支持一个独立知识点。

### 卡片 1｜汗液蒸发带走热量
- **核心知识**：汗液蒸发通过吸收热量带走热量。
- **简明解释**：原文把汗液带走热量与蒸发吸热联系起来。
- **例子（原文）**：汗液蒸发带走热量。
- **原文依据**：“蒸发吸收热量，汗液蒸发因此带走热量。”
```

### 没有原文例子的短文章

输入：

```text
气压降低时水的沸点降低。
```

输出示例：

```markdown
共 1 张知识卡片。原文仅支持一个独立知识点。

### 卡片 1｜气压影响水的沸点
- **核心知识**：气压降低时，水的沸点降低。
- **简明解释**：原文说明了气压降低时水的沸点变化，未进一步解释原因。
- **自测问题**：气压降低时，水的沸点如何变化？
- **参考答案**：降低。
- **原文依据**：“气压降低时水的沸点降低。”
```

以上展示输出结构；具体措辞由执行 Skill 的模型生成。

## 验证与许可证

本 Skill 使用官方 `init_skill.py` 初始化，已通过 `quick_validate.py` 结构验证。项目不附带这两个开发工具。

[测试记录](tests/knowledge-cards.md)包含科普粘贴输入、Markdown 操作指南和 TXT 短观点的实际输出，分别生成 6、6、1 张卡片，并检查了去重、原文限定及正文指令干扰。结构验证不等同于内容准确性验证，当前样例未覆盖所有领域和长文。
